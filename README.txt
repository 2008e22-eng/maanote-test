MaaNote v0.9 RC2 - GitHub Pages smartphone test package

Purpose: public TEST URL for smartphone/PWA/offline testing.
Firebase: not used.
Personal data: stored in IndexedDB on the device.
Admin and v9.6 migration pages are intentionally NOT included in this package.

Upload every file in this folder to the root of the maanote-test repository.
Then enable GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).
